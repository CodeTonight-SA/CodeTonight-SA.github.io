01 -- Four names, one job

Four names, one job

GRIP applies rules, checks its knowledge and records its work. HAL connects models and brings in a separate judge. HAPPI defines the messages. GRASP lets you check the records.

Explore GRIP, HAL, HAPPI, GRASP.

02 -- GRIP

GRIP: rules that run as code

A program outside the model stops recognised dangerous commands before they run. It blocks an unapproved force-push, recognised secret reads and database dumps.

By default, it refuses unsupported test counts and typed merges with failing checks. Checks must leave a route to fix what they block.

The test-count and failing-check gates have overrides that leave a log entry. If a check itself breaks, the action goes through. Habits can still fail.

Read the rules and their limits.

03 -- GRIP

GRIP: it tests itself and shows the score

Changes in its improvement loops come with a prediction that could be false and a date to check it.

On 1 November 2026, only 13 of 335 verdicts rested on a resolvable metric. The other 322 are not evidence.

04 -- GRIP

GRIP: it checks what it knows first

GRIP checks its existing knowledge before searching elsewhere. It uses what it finds and writes back anything new.

On 572 held-out questions, keyword search found the right record in the top three 87.9% of the time. Keyword plus meaning search reached 89.0%. The embedding store, as wired for that test, reached 50.0%.

Keyword search now comes first. When a search fails, GRIP names the stores it searched instead of claiming the information does not exist.

Read the memory comparison.

05 -- HAL

HAL: any model, and a judge who is not the author

HAL gives providers the same calling interface. If a provider is slow or unavailable, it routes to another and records which answered.

For high-stakes calls, models from different companies answer the same question. A model from another company judges, and the verdict is sealed for checking later.

Reviews of GRIP’s code use other companies’ models and a separate judge. A concern can block a merge only if it quotes the relevant line.

A failed quotation check does not make a concern false. When GRIP tested rejected concerns, 14 of 14 were real.

Explore HAL and read how GRIP uses review.

06 -- HAPPI

HAPPI: one file you can run

HAPPI is documentation, a program and a specification in the same file. Run bash happi.md to run its quickstart.

One message goes in and a stream of results comes out. The current version accepts versions back to 1.0.

HAPPI/1.4 added pre-registered commitments. A recorded reasoning trace cannot settle a claim. A model’s account of its reasoning is itself a claim, not evidence.

Read and run HAPPI.

07 -- GRASP

GRASP: check it without us

GRASP writes and re-checks records under the AGPL-3.0 licence. Its checker needs no GRIP, HAL, network or account.

Change a record in the browser demonstration and inspect the failed checks. A quotation absent from the supplied source fails the quotation check.

Try the demonstration, read the source or run the checker.

08 -- The record, and what it does not prove

The record, and what it does not prove

The record links decisions, the beliefs behind them and quotation checks. It covers GRIP’s main paths, not every surface.

The chain is tamper-evident. Someone with write access can recompute the seals. Compare them against a root you kept elsewhere before the change.

A seal does not prove a decision was right. A quotation check does not prove the quoted words support an argument. Reading records back does not reproduce a model run.

Publishing and Bitcoin stamps stopped from 25 September to 1 November 2026, because the publishing machine’s redaction filter was incomplete. Both run again.

The public chain shows order, not completeness. GRIP’s private source prevents a stranger from matching every row to its code.

Inspect the public decision chain.

09 -- Open and private

Open and private

HAPPI and GRASP are open. GRIP and HAL repositories are private today. The node installer needs private repositories, so a stranger cannot start a node today.

Our own Internet-Draft is written and not yet posted. Direct checking between nodes remains in progress, including how strangers obtain the right verification key.

Open the protocol, inspect the public implementation or read the current limits.
